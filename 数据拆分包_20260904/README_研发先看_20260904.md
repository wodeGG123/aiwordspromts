# 腐化魔王危机 AI交互研发接入包

版本：2026.09.04.2

研发只需要先看三处：

1. `状态拼装索引_20260904.json`：operation到模板、上下文和目录的固定映射。
2. `腐化魔王危机_预切片积木入口_20260904.mjs`：生产调用入口；返回systemPrompt、userPrompt、fullPrompt、bricks和contextScope。
3. `03_完整流程模拟`：7次真实完整请求与响应，覆盖五模板及六种operation。

不要在业务代码中扫描或裁剪提示词字符串。调用`prepareAiMessages`并把返回的systemPrompt作为system消息、userPrompt作为user消息即可。AI响应直接送入流式解析器；完整YAML、Schema和业务快照校验通过前不得推进状态。

`pending_interaction.event_output`必须保存完整的新事件解析对象。若只保存字符串、摘要或options，会导致后续检定、战斗和结算失去真实剧情上下文。`settle_check`和`battle_result`还必须把上一份完整检定/战斗输出放入`pending_interaction.resolution_output`。

## 五模板输出约束（2026.09.04.2 新增）

模板结构契约只有一份真源：`01_共享积木/五模板输出约束_20260904.yaml`。

- `00_源包/输出约束Schema_20260904.mjs`把它渲染成逐字段约束文本，追加到引擎积木末尾。引擎包里不再内嵌「输出格式模板」示例段落，因此提示词里没有任何示例角色名、示例事件ID、示例奖励ID或示例正文，AI不会照抄。
- `04_验证工具/输出约束校验器.mjs`用同一份规格反向校验AI实际输出：根层键集合与顺序、字段顺序、未知字段、必填与条件必填、类型、枚举、区间、数组长度、互斥组，以及`event_id`/`scene_name`/`template_name`与程序锁定值是否逐字一致。服务端只做转发，解析后由客户端调用该校验器。
- 契约变了只需要改这一份YAML，不要在引擎包或校验器里另写一份字段清单。

## 研发包产物与代码的同步

引擎包一改，`02_按状态预切片`与`03_完整流程模拟`里的提示词产物就会过期。两条命令覆盖这件事：

```
node 数据拆分包_20260904/04_验证工具/重新生成预切片与模拟_20260904.mjs           # 重新生成并重建发布清单
node 数据拆分包_20260904/04_验证工具/重新生成预切片与模拟_20260904.mjs --check   # 只检查是否漂移
node 数据拆分包_20260904/04_验证工具/验证完整模拟_20260904.mjs                   # 全量一致性验证
```

`验证完整模拟`会断言：完整流程模拟的system prompt能被生产入口逐字重建；AI实际输出既能被流式解析器解析，也能通过五模板输出约束校验；预切片的四块积木能按拼装顺序拼成完整示例且引擎积木不含demo实体；发布清单的字节数与sha256与磁盘一致。
